# **Fruit Info AI**
This is a helpful application built with Django and utilizes a classification model built with TensorFlow to classify up to 100 types of fruit and their health benefits.  

The inference model is ONNX format integrated with an AI agent leveraging [Groq](https://groq.com/) for detailed inference to deliver excellent result.  

A lightweight version is hosted and can be accessed at [amunipelumi.online](https://amunipelumi.online/).  

## **How to setup on local machine:**

### **Windows**  

Clone this repository - *https://github.com/amunipelumi/fruit-info-ai.git*  
Create a virtual environment - *py -m venv venv*
